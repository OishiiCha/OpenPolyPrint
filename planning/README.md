# OpenPolyPrint Future Planning

This directory contains markdown planning documents for future features and contingency plans.

## Documents

- [AnkerMake M5/M5C Bluetooth Reverse Engineering](ankermake-m5c-bluetooth-re.md) — Plan to reverse engineer the BLE pairing protocol so we can set up printers without the EufyMake app
- [EufyMake Shutdown Contingency](eufymake-shutdown-contingency.md) — What breaks and what still works if EufyMake cloud shuts down

## How to Use

1. Create new `.md` files in this directory for each planning topic
2. They will automatically appear on the Planning page in the app
3. Edit them in the app or directly in this directory
4. Use checkboxes (`- [ ]`) for trackable tasks
